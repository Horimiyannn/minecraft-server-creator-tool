# Backups Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Snapshot and restore a server's state — two kinds (world, full), three triggers (panel button, in-game `!backup` chat command, per-server interval schedule) — with keep-N retention, download, and no mod installed on the server.

**Architecture:** `backend/src/backups/` owns the engine. Pure modules (`archive-paths.ts`, `chat-command.ts`) hold all the parsing and path-selection logic so it can be table-tested against real log lines. `BackupService` is the single code path every trigger funnels into, holding a per-server single-flight lock and the `save-off`/`save-on` guarantee. `BackupRepository` is the only Prisma consumer. `ChatTriggerService` reads chat off the existing docker log stream — which this plan refactors from one sink per server to many — and replies over the existing RCON pool. `BackupScheduleService` runs plain `setInterval` timers, so no scheduling dependency is added.

**Tech Stack:** Nest 11 (CommonJS), Prisma 6.19 + SQLite, TypeScript 5.9, Jest 29 + ts-jest, system `tar` 1.35 with `--zstd` (host has `/usr/bin/zstd`), `rcon-client`; frontend Next 16, TanStack Query, Jest + Testing Library.

**Spec:** `docs/superpowers/specs/2026-09-12-files-backups-packs-design.md`

**Depends on:** `docs/superpowers/plans/2026-09-12-file-manager.md` — specifically `backend/src/servers/paths.ts` (`backupsDir`, `dataDir`) and `ServersService.assertServerExists`. Do not start this plan before those exist.

## Global Constraints

- TypeScript **5.9**, Prisma **6.19**, Nest **11**, CommonJS output. **Never** upgrade to TypeScript 7 or Prisma 7.
- pnpm (`pnpm@10.28.1`). Prisma commands run against the backend package: `pnpm --filter ./backend run prisma:migrate`.
- **Architecture rule (binding):** controller → service → repository. `BackupRepository` is the only file in this plan that may import `PrismaService`.
- Inject services as `*Service`-suffixed fields. All logic in services; controllers only route.
- `save-on` must run in a `finally` on every path that ran `save-off`. A server left with saves disabled is the one unacceptable outcome of this feature.
- Chat may trigger **world backups only**. No `!restore`, no in-game listing. Restore is panel-only.
- Retention inputs are clamped to **1–20**; interval floor is **5 minutes**.
- Never bypass git hooks (`--no-verify`). pre-push runs `pnpm build && pnpm test && pnpm test:e2e && pnpm fallow`.
- Commit messages: conventional-commit title only, no body.
- Backend unit tests: `pnpm --filter ./backend exec jest src/backups/`. Full: `pnpm --filter ./backend test`.

```ts
// backend/src/backups/backup.repository.ts
import { Injectable, NotFoundException } from '@nestjs/common';
import { Prisma } from '@prisma/client';
import { PrismaService } from '../prisma/prisma.service';

export type BackupKind = 'world' | 'full';
export type BackupTrigger = 'manual' | 'chat' | 'schedule';

export interface BackupRecord {
  id: string;
  serverId: string;
  kind: BackupKind;
  trigger: BackupTrigger;
  label: string | null;
  path: string;
  sizeBytes: bigint;
  createdAt: Date;
}

export interface CreateBackupData {
  serverId: string;
  kind: BackupKind;
  trigger: BackupTrigger;
  label?: string | null;
  path: string;
  sizeBytes: bigint;
}

export interface ScheduleRecord {
  serverId: string;
  worldEveryMin: number | null;
  fullEveryMin: number | null;
  keepWorld: number;
  keepFull: number;
  skipWhenEmpty: boolean;
  chatEnabled: boolean;
}

export type ScheduleUpdate = Omit<ScheduleRecord, 'serverId'>;

/** Applied when a server has never had a schedule saved. */
const SCHEDULE_DEFAULTS: ScheduleUpdate = {
  worldEveryMin: null,
  fullEveryMin: null,
  keepWorld: 12,
  keepFull: 5,
  skipWhenEmpty: true,
  chatEnabled: true,
};

@Injectable()
export class BackupRepository {
  constructor(private readonly prismaService: PrismaService) {}

  async create(data: CreateBackupData): Promise<BackupRecord> {
    return (await this.prismaService.backup.create({
      data,
    })) as BackupRecord;
  }

  async listByServer(serverId: string): Promise<BackupRecord[]> {
    return (await this.prismaService.backup.findMany({
      where: { serverId },
      orderBy: { createdAt: 'desc' },
    })) as BackupRecord[];
  }

  async listByKindOldestFirst(
    serverId: string,
    kind: BackupKind,
  ): Promise<BackupRecord[]> {
    return (await this.prismaService.backup.findMany({
      where: { serverId, kind },
      orderBy: { createdAt: 'asc' },
    })) as BackupRecord[];
  }

  async findById(id: string): Promise<BackupRecord | null> {
    return (await this.prismaService.backup.findUnique({
      where: { id },
    })) as BackupRecord | null;
  }

  async delete(id: string): Promise<void> {
    try {
      await this.prismaService.backup.delete({ where: { id } });
    } catch (error) {
      if (
        error instanceof Prisma.PrismaClientKnownRequestError &&
        error.code === 'P2025'
      ) {
        throw new NotFoundException(`Backup "${id}" not found`);
      }
      throw error;
    }
  }

  async totalBytes(serverId: string): Promise<bigint> {
    const result = await this.prismaService.backup.aggregate({
      where: { serverId },
      _sum: { sizeBytes: true },
    });
    return result._sum.sizeBytes ?? 0n;
  }

  async getSchedule(serverId: string): Promise<ScheduleRecord> {
    const row = await this.prismaService.backupSchedule.findUnique({
      where: { serverId },
    });
    return row ?? { serverId, ...SCHEDULE_DEFAULTS };
  }

  async listSchedules(): Promise<ScheduleRecord[]> {
    return (await this.prismaService.backupSchedule.findMany()) as ScheduleRecord[];
  }

  async upsertSchedule(
    serverId: string,
    data: ScheduleUpdate,
  ): Promise<ScheduleRecord> {
    return (await this.prismaService.backupSchedule.upsert({
      where: { serverId },
      create: { serverId, ...data },
      update: data,
    })) as ScheduleRecord;
  }
}
```

```ts
// backend/src/backups/archive-paths.ts
import { BackupKind } from './backup.repository';

/**
 * Paths excluded from a full backup. Rebuildable or noisy only — `mods/`,
 * `plugins/` and `config/` must stay, or a "full" backup cannot revive a
 * modded server. `./*.jar` is anchored at the root on purpose: it drops the
 * server jar without touching mod jars in `mods/`.
 */
export const FULL_EXCLUDES = [
  './logs',
  './cache',
  './crash-reports',
  './libraries',
  './versions',
  './*.jar',
];

export function levelName(serverProperties: string): string {
  for (const line of serverProperties.split('\n')) {
    const trimmed = line.trim();
    if (trimmed.startsWith('#')) continue;
    const match = /^level-name\s*=\s*(.*)$/.exec(trimmed);
    if (match) {
      const value = match[1].trim();
      if (value) return value;
    }
  }
  return 'world';
}

/** The dimension folders a world snapshot covers, filtered to what exists. */
export function worldDirs(level: string, existing: string[]): string[] {
  const candidates = [level, `${level}_nether`, `${level}_the_end`];
  const present = new Set(existing);
  return candidates.filter((dir) => present.has(dir));
}

export function archiveName(
  kind: BackupKind,
  at: Date,
  label?: string | null,
): string {
  const stamp = at
    .toISOString()
    .replace(/[-:]/g, '')
    .replace('T', '-')
    .slice(0, 15);
  const suffix = label ? `-${slug(label)}` : '';
  return `${kind}-${stamp}${suffix}.tar.zst`;
}

/**
 * Labels come from chat, so they are untrusted: reduce to lowercase words
 * joined by hyphens, which cannot contain a separator or a dot-dot.
 */
function slug(label: string): string {
  return label
    .toLowerCase()
    .split(/[^a-z0-9]+/)
    .filter(Boolean)
    .join('-')
    .slice(0, 40);
}
```

```ts
// backend/src/backups/chat-command.ts
export interface ChatCommand {
  player: string;
  command: string;
  arg?: string;
}

/**
 * Chat lines across loaders and versions:
 *   [10:31:02] [Server thread/INFO]: <Steve> !backup
 *   [10:31:02] [Async Chat Thread - #0/INFO]: [Not Secure] <Alex> !backup
 *   [10:31:02] [Server thread/INFO] [minecraft/MinecraftServer]: <Steve> !backup
 * The player name is taken from the log's own `<name>` marker, so nothing a
 * player types in the message body can impersonate someone else.
 */
const CHAT_LINE =
  /\[[^\]]*(?:Server thread|Async Chat Thread[^\]]*)\/INFO\](?:\s*\[[^\]]*\])?:\s*(?:\[Not Secure\]\s*)?<([^>]{1,32})>\s*(.*)$/;

const COMMAND = /^!([a-z]+)(?:\s+(.*))?$/i;

export function parseChatCommand(line: string): ChatCommand | null {
  const chat = CHAT_LINE.exec(line);
  if (!chat) return null;
  const [, player, message] = chat;
  const command = COMMAND.exec(message.trim());
  if (!command) return null;
  const arg = command[2]?.trim();
  return {
    player,
    command: command[1].toLowerCase(),
    arg: arg ? arg : undefined,
  };
}

/** `list` output, identical across vanilla, Paper, Forge and NeoForge. */
const PLAYER_COUNT = /There are (\d+)(?:\/\d+| of a max of \d+ players)/;

export function parsePlayerCount(listOutput: string): number | null {
  const match = PLAYER_COUNT.exec(listOutput);
  return match ? Number(match[1]) : null;
}

export function isJoinLine(line: string): boolean {
  return / joined the game\s*$/.test(line);
}
```

```ts
// backend/src/backups/tar.service.ts
import { Injectable } from '@nestjs/common';
import { spawn } from 'node:child_process';

export interface CreateTarOptions {
  cwd: string;
  paths: string[];
  excludes?: string[];
  dest: string;
}

export interface ExtractTarOptions {
  archive: string;
  dest: string;
}

/**
 * The only place this codebase shells out. GNU tar (1.35 on the host) with
 * --zstd is used rather than a JS tar because it preserves permissions and
 * symlinks correctly and compresses world data several times faster than
 * gzip — a 3 GB modded world is the normal case, not the edge case.
 */
@Injectable()
export class TarService {
  create(opts: CreateTarOptions): Promise<void> {
    const args = [
      '--zstd',
      ...(opts.excludes ?? []).map((pattern) => `--exclude=${pattern}`),
      '-cf',
      opts.dest,
      '-C',
      opts.cwd,
      ...opts.paths,
    ];
    return run('tar', args);
  }

  extract(opts: ExtractTarOptions): Promise<void> {
    return run('tar', ['--zstd', '-xf', opts.archive, '-C', opts.dest]);
  }
}

function run(command: string, args: string[]): Promise<void> {
  return new Promise<void>((resolve, reject) => {
    const child = spawn(command, args, { stdio: ['ignore', 'ignore', 'pipe'] });
    let stderr = '';
    child.stderr.on('data', (chunk: Buffer) => {
      stderr += chunk.toString('utf8');
    });
    child.on('error', reject);
    child.on('close', (code) =>
      code === 0
        ? resolve()
        : reject(new Error(`${command} exited ${code}: ${stderr.trim()}`)),
    );
  });
}
```

```ts
// backend/src/backups/backup.service.ts
import { ConflictException, Injectable, Logger } from '@nestjs/common';
import { mkdir, readdir, readFile, rm, stat } from 'node:fs/promises';
import * as path from 'node:path';
import {
  BackupKind,
  BackupRecord,
  BackupRepository,
  BackupTrigger,
} from './backup.repository';
import { TarService } from './tar.service';
import { ServersService } from '../servers/servers.service';
import { DockerService } from '../servers/docker.service';
import { RconService } from '../console/rcon.service';
import {
  archiveName,
  FULL_EXCLUDES,
  levelName,
  worldDirs,
} from './archive-paths';

/** Pause after `save-all flush` so the chunk writer lands before tar reads. */
const FLUSH_SETTLE_MS = 750;

@Injectable()
export class BackupService {
  private readonly logger = new Logger(BackupService.name);
  /** Per-server single-flight: schedule, chat and button cannot overlap. */
  private readonly running = new Set<string>();

  constructor(
    private readonly backupRepository: BackupRepository,
    private readonly tarService: TarService,
    private readonly serversService: ServersService,
    private readonly dockerService: DockerService,
    private readonly rconService: RconService,
  ) {}

  async create(
    serverId: string,
    kind: BackupKind,
    trigger: BackupTrigger,
    label?: string | null,
  ): Promise<BackupRecord> {
    await this.serversService.assertServerExists(serverId);
    if (this.running.has(serverId)) {
      throw new ConflictException(
        'a backup is already running for this server',
      );
    }
    this.running.add(serverId);
    try {
      return await this.run(serverId, kind, trigger, label);
    } finally {
      this.running.delete(serverId);
    }
  }

  private async run(
    serverId: string,
    kind: BackupKind,
    trigger: BackupTrigger,
    label?: string | null,
  ): Promise<BackupRecord> {
    const dataDir = this.dockerService.dataDir(serverId);
    const backupsDir = path.join(
      this.dockerService.serverRoot(serverId),
      'backups',
    );
    await mkdir(backupsDir, { recursive: true });

    const dest = path.join(backupsDir, archiveName(kind, new Date(), label));
    const paths = await this.pathsFor(serverId, kind, dataDir);
    const live = await this.isRunning(serverId);

    if (live) await this.rconService.send(serverId, 'save-off');
    try {
      if (live) {
        await this.rconService.send(serverId, 'save-all flush');
        await delay(FLUSH_SETTLE_MS);
      }
      await this.tarService.create({
        cwd: dataDir,
        paths,
        excludes: kind === 'full' ? FULL_EXCLUDES : undefined,
        dest,
      });
    } catch (error) {
      await rm(dest, { force: true });
      throw error;
    } finally {
      // Non-negotiable: a server left with saves disabled silently loses
      // everything on the next crash.
      if (live) {
        await this.rconService
          .send(serverId, 'save-on')
          .catch((error) =>
            this.logger.error(
              `save-on failed for ${serverId}: ${String(error)}`,
            ),
          );
      }
    }

    const info = await stat(dest);
    const record = await this.backupRepository.create({
      serverId,
      kind,
      trigger,
      label: label ?? null,
      path: dest,
      sizeBytes: BigInt(info.size),
    });
    await this.prune(serverId, kind);
    return record;
  }

  /** World snapshots take the level's dimension folders; full takes it all. */
  private async pathsFor(
    serverId: string,
    kind: BackupKind,
    dataDir: string,
  ): Promise<string[]> {
    if (kind === 'full') return ['.'];
    const properties = await readFile(
      path.join(dataDir, 'server.properties'),
      'utf8',
    ).catch(() => '');
    const existing = await readdir(dataDir).catch(() => [] as string[]);
    const dirs = worldDirs(levelName(properties), existing);
    if (dirs.length === 0) {
      throw new Error(`server "${serverId}" has no world directory yet`);
    }
    return dirs;
  }

  private async isRunning(serverId: string): Promise<boolean> {
    const containerId = await this.serversService
      .resolveContainerId(serverId)
      .catch(() => null);
    if (!containerId) return false;
    const status = await this.dockerService
      .inspect(containerId)
      .catch(() => null);
    return status?.running === true;
  }

  private async prune(serverId: string, kind: BackupKind): Promise<void> {
    const schedule = await this.backupRepository.getSchedule(serverId);
    const keep = kind === 'world' ? schedule.keepWorld : schedule.keepFull;
    const rows = await this.backupRepository.listByKindOldestFirst(
      serverId,
      kind,
    );
    for (const row of rows.slice(0, Math.max(0, rows.length - keep))) {
      await rm(row.path, { force: true }).catch(() => undefined);
      await this.backupRepository.delete(row.id).catch(() => undefined);
    }
  }

  list(serverId: string): Promise<BackupRecord[]> {
    return this.backupRepository.listByServer(serverId);
  }

  totalBytes(serverId: string): Promise<bigint> {
    return this.backupRepository.totalBytes(serverId);
  }

  async remove(serverId: string, backupId: string): Promise<void> {
    const record = await this.requireBackup(serverId, backupId);
    await rm(record.path, { force: true }).catch(() => undefined);
    await this.backupRepository.delete(record.id);
  }

  async pathFor(
    serverId: string,
    backupId: string,
  ): Promise<{ path: string; filename: string }> {
    const record = await this.requireBackup(serverId, backupId);
    return { path: record.path, filename: path.basename(record.path) };
  }

  async requireBackup(
    serverId: string,
    backupId: string,
  ): Promise<BackupRecord> {
    const record = await this.backupRepository.findById(backupId);
    if (!record || record.serverId !== serverId) {
      const { NotFoundException } = await import('@nestjs/common');
      throw new NotFoundException(`Backup "${backupId}" not found`);
    }
    return record;
  }
}

function delay(ms: number): Promise<void> {
  return new Promise((resolve) => setTimeout(resolve, ms));
}
```

```ts
// backend/src/backups/backup.service.ts — additions
import { rename } from 'node:fs/promises';

  /**
   * Panel-only: restore stops the server, replaces files, and restarts it if
   * it was running. A full restore moves the live data dir aside instead of
   * deleting it, so a failed extraction can be rolled back — that rename is
   * the undo, which is why restore needs no pre-snapshot of its own.
   */
  async restore(serverId: string, backupId: string): Promise<void> {
    await this.serversService.assertServerExists(serverId);
    if (this.running.has(serverId)) {
      throw new ConflictException('a backup is already running for this server');
    }
    this.running.add(serverId);
    try {
      const record = await this.requireBackup(serverId, backupId);
      const wasRunning = await this.isRunning(serverId);
      if (wasRunning) await this.serversService.stop(serverId);
      try {
        if (record.kind === 'full') {
          await this.restoreFull(serverId, record.path);
        } else {
          await this.restoreWorld(serverId, record.path);
        }
      } finally {
        if (wasRunning) await this.serversService.start(serverId);
      }
    } finally {
      this.running.delete(serverId);
    }
  }

  private async restoreFull(serverId: string, archive: string): Promise<void> {
    const dataDir = this.dockerService.dataDir(serverId);
    const aside = `${dataDir}.restoring-${Date.now()}`;
    await rename(dataDir, aside);
    await mkdir(dataDir, { recursive: true });
    try {
      await this.tarService.extract({ archive, dest: dataDir });
    } catch (error) {
      await rm(dataDir, { recursive: true, force: true });
      await rename(aside, dataDir);
      throw error;
    }
    await rm(aside, { recursive: true, force: true });
  }

  /** World restore replaces the dimension folders in place, nothing else. */
  private async restoreWorld(serverId: string, archive: string): Promise<void> {
    const dataDir = this.dockerService.dataDir(serverId);
    const properties = await readFile(
      path.join(dataDir, 'server.properties'),
      'utf8',
    ).catch(() => '');
    const existing = await readdir(dataDir).catch(() => [] as string[]);
    const dirs = worldDirs(levelName(properties), existing);
    const aside = new Map<string, string>();
    for (const dir of dirs) {
      const from = path.join(dataDir, dir);
      const to = `${from}.restoring-${Date.now()}`;
      await rename(from, to);
      aside.set(from, to);
    }
    try {
      await this.tarService.extract({ archive, dest: dataDir });
    } catch (error) {
      for (const [from, to] of aside) {
        await rm(from, { recursive: true, force: true });
        await rename(to, from);
      }
      throw error;
    }
    for (const to of aside.values()) {
      await rm(to, { recursive: true, force: true });
    }
  }
```

```ts
// backend/src/console/log-stream.service.ts — replacing the LogStream shape
interface LogStream {
  stream: NodeJS.ReadableStream;
  buffer: string;
  listeners: Set<(line: string) => void>;
}

@Injectable()
export class LogStreamService {
  private readonly streams = new Map<string, LogStream>();
  private readonly starting = new Map<string, Promise<LogStream>>();

  constructor(
    private readonly dockerService: DockerService,
    private readonly serversService: ServersService,
  ) {}

  /**
   * Attach a sink to this server's log stream, creating the docker stream on
   * first use. Returns a release function; the stream is torn down when the
   * last listener releases, so the console gateway and the backup chat
   * trigger can watch the same server independently.
   */
  async subscribe(
    serverId: string,
    onLine: (line: string) => void,
  ): Promise<() => void> {
    const entry = await this.ensure(serverId);
    entry.listeners.add(onLine);
    let released = false;
    return () => {
      if (released) return;
      released = true;
      entry.listeners.delete(onLine);
      if (entry.listeners.size === 0) this.teardown(serverId, entry);
    };
  }

  private ensure(serverId: string): Promise<LogStream> {
    const existing = this.streams.get(serverId);
    if (existing) return Promise.resolve(existing);
    const pending = this.starting.get(serverId);
    if (pending) return pending;

    const promise = (async () => {
      const containerId =
        await this.serversService.resolveContainerId(serverId);
      const stream = await this.dockerService.logs(containerId, { tail: 200 });
      const entry: LogStream = { stream, buffer: '', listeners: new Set() };
      this.streams.set(serverId, entry);
      stream.on('data', (chunk: Buffer) => this.fanOut(entry, chunk));
      stream.on('end', () => this.finish(serverId, entry));
      stream.on('error', () => this.finish(serverId, entry));
      return entry;
    })().finally(() => this.starting.delete(serverId));

    this.starting.set(serverId, promise);
    return promise;
  }

  private teardown(serverId: string, entry: LogStream): void {
    if (this.streams.get(serverId) !== entry) return;
    this.streams.delete(serverId);
    (entry.stream as unknown as { destroy?: () => void }).destroy?.();
  }

  private fanOut(entry: LogStream, chunk: Buffer): void {
    entry.buffer += chunk.toString('utf8');
    const lines = entry.buffer.split('\n');
    entry.buffer = lines.pop() ?? '';
    for (const line of lines) {
      const clean = line.replace(/\r$/, '');
      for (const listener of entry.listeners) listener(clean);
    }
  }

  private finish(serverId: string, entry: LogStream): void {
    if (this.streams.get(serverId) !== entry) return;
    if (entry.buffer) {
      const clean = entry.buffer.replace(/\r$/, '');
      for (const listener of entry.listeners) listener(clean);
    }
    this.streams.delete(serverId);
  }
}
```

```ts
// backend/src/backups/chat-trigger.service.ts
import { Injectable, Logger, OnModuleInit } from '@nestjs/common';
import { readFile } from 'node:fs/promises';
import * as path from 'node:path';
import { LogStreamService } from '../console/log-stream.service';
import { RconService } from '../console/rcon.service';
import { DockerService } from '../servers/docker.service';
import { BackupService } from './backup.service';
import { BackupRepository } from './backup.repository';
import { isJoinLine, parseChatCommand } from './chat-command';

/** One backup per player per server per this window. */
const RATE_LIMIT_MS = 5 * 60 * 1000;

@Injectable()
export class ChatTriggerService implements OnModuleInit {
  private readonly logger = new Logger(ChatTriggerService.name);
  private readonly releases = new Map<string, () => void>();
  private readonly lastUse = new Map<string, number>();
  private readonly seen = new Set<string>();

  constructor(
    private readonly logStreamService: LogStreamService,
    private readonly rconService: RconService,
    private readonly backupService: BackupService,
    private readonly backupRepository: BackupRepository,
    private readonly dockerService: DockerService,
  ) {}

  async onModuleInit(): Promise<void> {
    for (const schedule of await this.backupRepository.listSchedules()) {
      if (schedule.chatEnabled) {
        await this.watch(schedule.serverId).catch((error) =>
          this.logger.warn(
            `chat trigger not attached for ${schedule.serverId}: ${String(error)}`,
          ),
        );
      }
    }
  }

  async watch(serverId: string): Promise<void> {
    if (this.releases.has(serverId)) return;
    const release = await this.logStreamService.subscribe(serverId, (line) =>
      this.onLine(serverId, line),
    );
    this.releases.set(serverId, release);
  }

  unwatch(serverId: string): void {
    this.releases.get(serverId)?.();
    this.releases.delete(serverId);
  }

  /** Has anyone been on since the last backup? Used by skipWhenEmpty. */
  playersSeen(serverId: string): boolean {
    return this.seen.has(serverId);
  }

  markPlayersSeen(serverId: string): void {
    this.seen.add(serverId);
  }

  clearPlayersSeen(serverId: string): void {
    this.seen.delete(serverId);
  }

  private onLine(serverId: string, line: string): void {
    if (isJoinLine(line)) this.seen.add(serverId);
    const parsed = parseChatCommand(line);
    // Chat may take world backups and nothing else: no restore, no listing.
    if (!parsed || parsed.command !== 'backup') return;
    void this.handle(serverId, parsed.player, parsed.arg);
  }

  private async handle(
    serverId: string,
    player: string,
    label?: string,
  ): Promise<void> {
    try {
      const ops = await this.readOps(serverId);
      if (!ops.some((name) => name.toLowerCase() === player.toLowerCase())) {
        await this.reply(serverId, player, 'Only server ops can run !backup.');
        return;
      }
      const key = `${serverId}:${player.toLowerCase()}`;
      const last = this.lastUse.get(key) ?? 0;
      if (Date.now() - last < RATE_LIMIT_MS) {
        await this.reply(
          serverId,
          player,
          'You backed up recently — please wait a few minutes.',
        );
        return;
      }
      this.lastUse.set(key, Date.now());

      await this.reply(serverId, player, 'Backing up the world…');
      const record = await this.backupService.create(
        serverId,
        'world',
        'chat',
        label,
      );
      this.clearPlayersSeen(serverId);
      await this.reply(
        serverId,
        player,
        `World backup done (${formatMb(record.sizeBytes)} MB).`,
      );
    } catch (error) {
      this.logger.warn(`chat backup failed for ${serverId}: ${String(error)}`);
      await this.reply(
        serverId,
        player,
        'Backup failed — check the panel.',
      ).catch(() => undefined);
    }
  }

  private async readOps(serverId: string): Promise<string[]> {
    // Re-read per command: op status changes in game and must take effect at
    // once, and the file is a few hundred bytes.
    const raw = await readFile(
      path.join(this.dockerService.dataDir(serverId), 'ops.json'),
      'utf8',
    ).catch(() => '[]');
    const parsed = JSON.parse(raw) as { name?: string }[];
    return parsed.map((entry) => entry.name ?? '').filter(Boolean);
  }

  private reply(
    serverId: string,
    player: string,
    text: string,
  ): Promise<string> {
    return this.rconService.send(
      serverId,
      `tellraw ${player} ${JSON.stringify({ text: `[backup] ${text}`, color: 'gray' })}`,
    );
  }
}

function formatMb(bytes: bigint): string {
  return (Number(bytes) / (1024 * 1024)).toFixed(1);
}
```

```ts
// backend/src/backups/backup-schedule.service.ts
import {
  BadRequestException,
  Injectable,
  Logger,
  OnModuleDestroy,
  OnModuleInit,
} from '@nestjs/common';
import {
  BackupKind,
  BackupRepository,
  ScheduleRecord,
  ScheduleUpdate,
} from './backup.repository';
import { BackupService } from './backup.service';
import { RconService } from '../console/rcon.service';
import { ChatTriggerService } from './chat-trigger.service';
import { parsePlayerCount } from './chat-command';

/** Below this, a tar of a large world can outlast its own interval. */
export const MIN_INTERVAL_MIN = 5;
export const MAX_KEEP = 20;

@Injectable()
export class BackupScheduleService implements OnModuleInit, OnModuleDestroy {
  private readonly logger = new Logger(BackupScheduleService.name);
  private readonly timers = new Map<string, NodeJS.Timeout[]>();

  constructor(
    private readonly backupRepository: BackupRepository,
    private readonly backupService: BackupService,
    private readonly rconService: RconService,
    private readonly chatTriggerService: ChatTriggerService,
  ) {}

  async onModuleInit(): Promise<void> {
    for (const schedule of await this.backupRepository.listSchedules()) {
      this.register(schedule);
    }
  }

  onModuleDestroy(): void {
    for (const timers of this.timers.values()) timers.forEach(clearInterval);
    this.timers.clear();
  }

  get(serverId: string): Promise<ScheduleRecord> {
    return this.backupRepository.getSchedule(serverId);
  }

  async save(
    serverId: string,
    update: ScheduleUpdate,
  ): Promise<ScheduleRecord> {
    validate(update);
    const saved = await this.backupRepository.upsertSchedule(serverId, update);
    this.register(saved);
    if (saved.chatEnabled) {
      await this.chatTriggerService
        .watch(serverId)
        .catch((error) => this.logger.warn(String(error)));
    } else {
      this.chatTriggerService.unwatch(serverId);
    }
    return saved;
  }

  /** Replace this server's timers with the ones its schedule now implies. */
  private register(schedule: ScheduleRecord): void {
    this.timers.get(schedule.serverId)?.forEach(clearInterval);
    const timers: NodeJS.Timeout[] = [];
    const add = (everyMin: number | null, kind: BackupKind): void => {
      if (!everyMin) return;
      timers.push(
        setInterval(
          () => void this.tick(schedule.serverId, kind),
          everyMin * 60 * 1000,
        ),
      );
    };
    add(schedule.worldEveryMin, 'world');
    add(schedule.fullEveryMin, 'full');
    this.timers.set(schedule.serverId, timers);
  }

  private async tick(serverId: string, kind: BackupKind): Promise<void> {
    try {
      const schedule = await this.backupRepository.getSchedule(serverId);
      if (schedule.skipWhenEmpty && !(await this.worthBackingUp(serverId))) {
        return;
      }
      await this.backupService.create(serverId, kind, 'schedule');
      this.chatTriggerService.clearPlayersSeen(serverId);
    } catch (error) {
      this.logger.warn(`scheduled ${kind} backup failed: ${String(error)}`);
    }
  }

  /**
   * "Empty" alone is not enough to skip: players who farmed for hours and
   * logged off would never get that session snapshotted. Back up when anyone
   * is online now, OR when anyone has been seen since the last backup.
   */
  private async worthBackingUp(serverId: string): Promise<boolean> {
    const output = await this.rconService
      .send(serverId, 'list')
      .catch(() => null);
    const online = output ? parsePlayerCount(output) : null;
    if (online !== null && online > 0) {
      this.chatTriggerService.markPlayersSeen(serverId);
      return true;
    }
    return this.chatTriggerService.playersSeen(serverId);
  }
}

function validate(update: ScheduleUpdate): void {
  for (const value of [update.worldEveryMin, update.fullEveryMin]) {
    if (value !== null && value < MIN_INTERVAL_MIN) {
      throw new BadRequestException(
        `interval must be at least ${MIN_INTERVAL_MIN} minutes`,
      );
    }
  }
  for (const keep of [update.keepWorld, update.keepFull]) {
    if (keep < 1 || keep > MAX_KEEP) {
      throw new BadRequestException(
        `keep count must be between 1 and ${MAX_KEEP}`,
      );
    }
  }
}
```

```ts
/** JSON has no BigInt, so sizes cross the wire as numbers. */
export interface PublicBackup extends Omit<BackupRecord, 'sizeBytes' | 'path'> {
  sizeBytes: number;
}

function toPublic(record: BackupRecord): PublicBackup {
  const { sizeBytes, path: _omit, ...rest } = record;
  return { ...rest, sizeBytes: Number(sizeBytes) };
}

@UseGuards(JwtAuthGuard)
@Controller('servers/:id/backups')
export class BackupsController {
  constructor(
    private readonly backupService: BackupService,
    private readonly backupScheduleService: BackupScheduleService,
  ) {}

  @Get()
  async list(@Param('id') id: string): Promise<PublicBackup[]> {
    return (await this.backupService.list(id)).map(toPublic);
  }

  @Post()
  async create(
    @Param('id') id: string,
    @Body() dto: CreateBackupDto,
  ): Promise<PublicBackup> {
    return toPublic(
      await this.backupService.create(id, dto.kind, 'manual', dto.label),
    );
  }

  @Get('schedule')
  schedule(@Param('id') id: string): Promise<ScheduleRecord> {
    return this.backupScheduleService.get(id);
  }

  @Put('schedule')
  saveSchedule(
    @Param('id') id: string,
    @Body() dto: ScheduleDto,
  ): Promise<ScheduleRecord> {
    return this.backupScheduleService.save(id, dto);
  }

  @Post(':backupId/restore')
  async restore(
    @Param('id') id: string,
    @Param('backupId') backupId: string,
  ): Promise<{ ok: true }> {
    await this.backupService.restore(id, backupId);
    return { ok: true };
  }

  @Get(':backupId/download')
  async download(
    @Param('id') id: string,
    @Param('backupId') backupId: string,
    @Res({ passthrough: true }) res: Response,
  ): Promise<StreamableFile> {
    const { path, filename } = await this.backupService.pathFor(id, backupId);
    res.set({
      'Content-Type': 'application/zstd',
      'Content-Disposition': `attachment; filename="${filename}"`,
    });

  }

  @Delete(':backupId')
  async remove(
    @Param('id') id: string,
    @Param('backupId') backupId: string,
  ): Promise<{ ok: true }> {
    await this.backupService.remove(id, backupId);
    return { ok: true };
```

```ts
// frontend/src/modules/backups/hooks.ts
'use client';
import { useMutation, useQuery, useQueryClient } from '@tanstack/react-query';
import { QUERY_KEYS } from '@/constants';
import type { Backup, BackupKind, BackupSchedule } from '@/types';
import {
  createBackup,
  deleteBackup,
  getSchedule,
  listBackups,
  restoreBackup,
  saveSchedule,
} from './api';

export function useBackups(serverId: string) {
  return useQuery<Backup[]>({
    queryKey: QUERY_KEYS.backups(serverId),
    queryFn: () => listBackups(serverId),
  });
}

export function useCreateBackup(serverId: string) {
  const qc = useQueryClient();
  return useMutation({
    mutationFn: (body: { kind: BackupKind; label?: string }) =>
      createBackup(serverId, body),
    onSuccess: () =>
      qc.invalidateQueries({ queryKey: QUERY_KEYS.backups(serverId) }),
  });
}

export function useBackupActions(serverId: string) {
  const qc = useQueryClient();
  const invalidate = () => {
    void qc.invalidateQueries({ queryKey: QUERY_KEYS.backups(serverId) });
    void qc.invalidateQueries({ queryKey: QUERY_KEYS.server(serverId) });
  };
  return {
    remove: useMutation({
      mutationFn: (backupId: string) => deleteBackup(serverId, backupId),
      onSuccess: invalidate,
    }),
    restore: useMutation({
      mutationFn: (backupId: string) => restoreBackup(serverId, backupId),
      onSuccess: invalidate,
    }),
  };
}

export function useBackupSchedule(serverId: string) {
  return useQuery<BackupSchedule>({
    queryKey: QUERY_KEYS.backupSchedule(serverId),
    queryFn: () => getSchedule(serverId),
  });
}

export function useSaveBackupSchedule(serverId: string) {
  const qc = useQueryClient();
  return useMutation({
    mutationFn: (body: Omit<BackupSchedule, 'serverId'>) =>
      saveSchedule(serverId, body),
    onSuccess: () =>
      qc.invalidateQueries({ queryKey: QUERY_KEYS.backupSchedule(serverId) }),
  });
}
```

```tsx
// frontend/src/modules/backups/components/ScheduleForm.tsx
'use client';
import { useState } from 'react';
import { Button, Checkbox, Input, Select } from '@ui';
import { errorText } from '@/lib/errors';
import type { BackupSchedule } from '@/types';
import { useSaveBackupSchedule } from '../hooks';

const MAX_KEEP = 20;
const MIN_MINUTES = 5;

/** Minutes → the largest whole unit that still divides evenly. */
function split(minutes: number | null): {
  value: number;
  unit: 'minutes' | 'hours';
} {
  if (!minutes) return { value: 0, unit: 'minutes' };
  return minutes % 60 === 0
    ? { value: minutes / 60, unit: 'hours' }
    : { value: minutes, unit: 'minutes' };
}

function toMinutes(value: number, unit: 'minutes' | 'hours'): number | null {
  if (!value) return null;
  return unit === 'hours' ? value * 60 : value;
}

export function ScheduleForm({
  serverId,
  schedule,
}: {
  serverId: string;
  schedule: BackupSchedule;
}) {
  const world = split(schedule.worldEveryMin);
  const full = split(schedule.fullEveryMin);
  const [worldValue, setWorldValue] = useState(world.value);
  const [worldUnit, setWorldUnit] = useState(world.unit);
  const [fullValue, setFullValue] = useState(full.value);
  const [fullUnit, setFullUnit] = useState(full.unit);
  const [keepWorld, setKeepWorld] = useState(schedule.keepWorld);
  const [keepFull, setKeepFull] = useState(schedule.keepFull);
  const [skipWhenEmpty, setSkipWhenEmpty] = useState(schedule.skipWhenEmpty);
  const [chatEnabled, setChatEnabled] = useState(schedule.chatEnabled);
  const save = useSaveBackupSchedule(serverId);

  const clampKeep = (value: number) =>
    Math.min(MAX_KEEP, Math.max(1, Math.round(value) || 1));

  function submit(): void {
    const worldEveryMin = toMinutes(worldValue, worldUnit);
    const fullEveryMin = toMinutes(fullValue, fullUnit);
    save.mutate({
      worldEveryMin:
        worldEveryMin && worldEveryMin < MIN_MINUTES
          ? MIN_MINUTES
          : worldEveryMin,
      fullEveryMin:
        fullEveryMin && fullEveryMin < MIN_MINUTES ? MIN_MINUTES : fullEveryMin,
      keepWorld: clampKeep(keepWorld),
      keepFull: clampKeep(keepFull),
      skipWhenEmpty,
      chatEnabled,
    });
  }

  return (
    <div className="flex flex-col gap-3 rounded border border-neutral-800 p-4">
      <h3 className="font-semibold">Schedule</h3>
      <div className="flex flex-wrap items-end gap-3">
        <Input
          type="number"
          label="World every"
          min={0}
          value={worldValue}
          onChange={(e) => setWorldValue(Number(e.target.value))}
        />
        <Select
          label="World unit"
          value={worldUnit}
          onChange={(e) => setWorldUnit(e.target.value as 'minutes' | 'hours')}
        >
          <option value="minutes">minutes</option>
          <option value="hours">hours</option>
        </Select>
        <Input
          type="number"
          label="Full every"
          min={0}
          value={fullValue}
          onChange={(e) => setFullValue(Number(e.target.value))}
        />
        <Select
          label="Full unit"
          value={fullUnit}
          onChange={(e) => setFullUnit(e.target.value as 'minutes' | 'hours')}
        >
          <option value="minutes">minutes</option>
          <option value="hours">hours</option>
        </Select>
      </div>
      <p className="text-xs text-neutral-500">
        0 turns that schedule off. Minimum interval is 5 minutes.
      </p>
      <div className="flex flex-wrap items-end gap-3">
        <Input
          type="number"
          label="Keep world backups"
          min={1}
          max={MAX_KEEP}
          value={keepWorld}
          onChange={(e) => setKeepWorld(Number(e.target.value))}
        />
        <Input
          type="number"
          label="Keep full backups"
          min={1}
          max={MAX_KEEP}
          value={keepFull}
          onChange={(e) => setKeepFull(Number(e.target.value))}
        />
      </div>
      <Checkbox
        checked={skipWhenEmpty}
        onChange={setSkipWhenEmpty}
        label="Skip scheduled backups while nobody has played since the last one"
      />
      <Checkbox
        checked={chatEnabled}
        onChange={setChatEnabled}
        label="Allow !backup in chat (server ops only, world snapshots only)"
      />
      <div>
        <Button onClick={submit} disabled={save.isPending}>
          Save schedule
        </Button>
      </div>
      {save.isError && <p className="text-red-400">{errorText(save.error)}</p>}
    </div>
  );
}
```
